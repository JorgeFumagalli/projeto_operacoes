# Dados

Nenhum lançamento empresarial acompanha o repositório. `src/gerar_demo.py` cria registros inteiramente fictícios, sem usar clientes, produtos, placas, motoristas, lotes ou pedidos reais. A base sintética serve para executar o código e demonstrar erros de qualidade; não reproduz os indicadores do estudo real.

Arquivos reais, se usados localmente, devem permanecer em `data/private/`, ignorada pelo Git. A leitura de XLSX do código atende ao layout específico do diário de 2025; a planilha histórica inicial tem outro layout.
